## Important boundary

FastAPI is not the whole runtime. Notes distinguish behavior owned by HTTP, ASGI, Uvicorn, Starlette, FastAPI, Pydantic, SQLAlchemy, Alembic, PostgreSQL, proxies, third-party packages, and application architecture.

This repository improves measurable readiness and engineering judgment. It does not guarantee an interview outcome or employment.

## Microservices and distributed service engineering

The appended `MSV` domain deepens existing RabbitMQ and gRPC foundations into decomposition, broker correctness, delivery semantics, outbox/inbox, sagas, data ownership, resilience, observability, security, testing, deployment, incidents, and governance. Start with the [RabbitMQ path](LEARNING_PATHS.md#rabbitmq-reliable-async-services), the [complete microservices path](LEARNING_PATHS.md#microservices-distributed-service-engineering), or the [senior design/operations path](LEARNING_PATHS.md#senior-microservices-design-operations).
